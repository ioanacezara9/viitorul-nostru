VIITORUL NOSTRU — APLICAȚIE WEB KAWAII GRATUITĂ
================================================

Aceasta este o aplicație web (PWA) personalizată pentru Oana, cu cele șase fotografii încărcate.
Data afișată: 25 iulie 2026. Culori: roz pastel și lila deschis.

PREVIZUALIZARE PE WINDOWS
-------------------------
1. Extrage arhiva ZIP.
2. Deschide folderul „our-future-web”.
3. Dă dublu clic pe index.html pentru a vedea aplicația în browser.
   Unele funcții PWA/offline necesită publicarea pe HTTPS.

PUBLICARE GRATUITĂ CU GITHUB PAGES
----------------------------------
1. Creează sau accesează un cont gratuit: https://github.com/
2. Creează un repository PUBLIC nou, numit: our-future
   Notă: GitHub Pages în planul gratuit necesită un repository public.
3. Încarcă în rădăcina repository-ului conținutul acestui folder:
   index.html, styles.css, app.js, manifest.webmanifest, sw.js și folderul assets.
4. Deschide Settings > Pages.
5. La „Build and deployment”, alege „Deploy from a branch”.
6. Selectează branch „main” și folderul „/(root)”, apoi apasă Save.
7. Așteaptă publicarea și deschide adresa oferită de GitHub.
8. Pe iPhone, deschide linkul în Safari > Share/Partajare > Add to Home Screen/Adaugă la ecranul principal.

CONFIDENȚIALITATE
-----------------
Repository-urile publice GitHub Pages sunt accesibile public. Oricine găsește adresa site-ului poate vedea fotografiile și conținutul. Nu încărca fotografii intime sau informații sensibile.

PERSONALIZARE
-------------
Editează index.html pentru texte, scrisori, descrieri și cronologie.
Editează app.js pentru lista motivelor și mesajul-surpriză.
Înlocuiește fotografiile din assets păstrând aceleași nume de fișiere.
Păstrează numele fișierelor imaginilor dacă nu actualizezi și referințele din cod.

MUZICĂ
------
Cele două melodii au linkuri de căutare către Spotify și Apple Music:
- DAISIES — Justin Bieber
- As Long As You Love Me — Justin Bieber

Linkurile deschid serviciul muzical; nu includ fișiere audio sau redare audio încorporată.

Aplicația este un site web/PWA, nu o aplicație iOS nativă pentru App Store/TestFlight.
Poate fi adăugată pe ecranul principal al iPhone-ului din Safari.
